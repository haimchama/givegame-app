# GiveGame (givegame)

ערב גיוס תרומות בסגנון משחק חי: האורחים נכנסים מהטלפון (QR או קוד בן 5 ספרות), מתחייבים לתרומות, משחקים בחידון, והכול מוצג בזמן אמת על מסך המקרן. אפליקציית Web של TKB, בלי התקנה.

## מסכים

| כתובת | למי |
|---|---|
| `/` | דף הבית: הצטרפות בקוד, יצירת אירוע, דמו |
| `/12345` או `/#/p/12345` | טלפון של אורח |
| `/#/screen/12345` | מסך המקרן (לפתוח במחשב שמחובר למקרן, ללחוץ "מסך מלא" ו"הפעלת צליל") |
| `/#/host/12345` | לוח המנחה (המפתח נשמר במכשיר שיצר את האירוע; "העתקת קישור מנחה" מעביר אותו למכשיר אחר) |
| `/#/demo` | דמו מלא בדפדפן עם משתתפים מדומים, בלי שרת |

## המשחק

- **רישום תרומות על ידי מתרימים**: כל מתרים נכנס מהטלפון ורושם תרומה שגייס – שם התורם (נשמר לגבייה, לא מוצג על המסך) וסכום. המתרים רואה כמה גייס ואת רשימת התרומות שרשם. על המסך מוצג שם המתרים. כל תרומה קופצת על המסך עם צליל; מעל 1,000 – זיקוקים.
- **מרוץ שולחנות**: פסים צבעוניים לכל קבוצה, כתר למובילה.
- **אתגר**: טיימר + מאצ'ינג ×2/×3 עם תקרה (למשל "התורם X מכפיל עד 10,000 ₪").
- **חידון**: שאלה עם 4 תשובות, ניקוד לפי מהירות. לכל שאלה סכום ספונסר שמתחלק בין הקבוצות לפי מספר העונים נכון.
- **אבני דרך**: 25/50/75/100% מהיעד – פנפרה וזיקוקים.
- **גמר חגיגי**: הסכום הכולל, דירוג הקבוצות ותודה.
- **מנחה**: רישום תרומה ידנית, מחיקת תרומה, ייצוא CSV לאקסל לגבייה, עריכת שאלות, קבוצות, יעד ושפת המקרן.

כל תרומה היא **התחייבות** בלבד; הגבייה נעשית אחרי האירוע מתוך קובץ ה-CSV.

## מבנה

```
public/            האתר (HTML/CSS/JS בלי שלב בנייה)
  app.js           כל המסכים, החיבור לשרת, והדמו
  shared/game.js   חוקי המשחק – משותף לשרת ולדמו
  vendor/qrcode.mjs  qrcode-generator (MIT)
src/worker.js      Cloudflare Worker + Durable Object לכל אירוע (WebSockets)
tests/             בדיקות חוקי המשחק
scripts/build-demo.mjs   בונה dist/demo.html – דמו בקובץ אחד
```

## פקודות

```
npm install
npm run dev      שרת מקומי: http://127.0.0.1:8787
npm test         בדיקות חוקי המשחק
npm run demo     dist/demo.html
```

## שרת

- Worker אחד בשם `givegame-api`, שמגיש גם את האתר וגם את ה-API, בכתובת `givegame.tkb-pro.com` (custom domain, `workers_dev: false`).
- כל אירוע הוא Durable Object (SQLite, נתמך בתוכנית החינמית) שמחזיק את המצב ואת חיבורי ה-WebSocket (Hibernation API). אירוע נמחק לבד 45 יום אחרי שנוצר.
- אין חשבונות, אין סודות, אין SDK חיצוני. נשמרים: שם שהאורח הקליד, שולחן, סכומי התחייבות ותשובות לחידון.

## הקמה (חיים)

1. ליצור repository פרטי `haimchama/givegame-app` ולדחוף אליו את התיקייה.
2. Cloudflare → Workers & Pages → Create → Import a repository → `givegame-app`.
   Build: `npm ci`, Deploy: `npx wrangler deploy`, ענף: `main`.
3. אחרי הפריסה הראשונה הכתובת `https://givegame.tkb-pro.com` עולה לבד (רשומת DNS נוצרת אוטומטית מה-route).
4. בדיקה: לפתוח את הכתובת, "יצירת אירוע חדש", לפתוח את המקרן במחשב ולהצטרף מהטלפון.

לפני אירוע אמיתי: ערב "חזרה גנרלית" עם 3–4 טלפונים, ולבדוק את ה-Wi-Fi באולם.
